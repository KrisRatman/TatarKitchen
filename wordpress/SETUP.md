# Установка сайта «Татарская кухня» на WordPress + WooCommerce

Эта папка — всё, что нужно, чтобы поднять сайт с корзиной, авторизацией
клиентов и панелью обработки заказов на вашем реальном хостинге.

## Что внутри

- `tatarskaya-kuhnya.zip` — тема сайта (вёрстка + логика корзины/checkout).
- `scripts/import-products.php` — загружает 9 блюд с ценами, категориями и фото.
- `scripts/setup-shipping.php` — создаёт способы получения заказа «Доставка»/«Самовывоз».
- `assets/food/*.png` — фотографии блюд для скрипта импорта.

## Шаги установки

1. **WordPress.** Установите WordPress на хостинге (обычно есть в панели
   управления хостингом — «1-клик установка»).

2. **WooCommerce.** В админке: `Плагины → Добавить новый` → найдите
   «WooCommerce» → «Установить» → «Активировать». При активации WooCommerce
   сам создаст нужные страницы (Магазин, Корзина, Оформление заказа,
   Личный кабинет).

   Если при активации откроется мастер настройки магазина — можно смело
   закрыть его, все настройки ниже задаются вручную и заменяют его.

3. **Тема.** `Внешний вид → Темы → Добавить новую → Загрузить тему` →
   выберите `tatarskaya-kuhnya.zip` → «Установить» → «Активировать».

4. **Валюта и страна магазина.** `WooCommerce → Настройки → Общие`:
   - Расположение магазина: Россия.
   - Продавать во все страны, куда осуществляется доставка: Россия (или
     нужный вам список).
   - Валюта: Российский рубль.

   `WooCommerce → Настройки → Дополнительно → Функции` — язык интерфейса
   должен быть русский (обычно подтягивается автоматически, если сайт на
   `ru_RU`; если нет — `Настройки → Общие → Язык сайта` в самой WordPress).

5. **Обязательная авторизация для заказа.** `WooCommerce → Настройки →
   Учётные записи и конфиденциальность`:
   - Снимите галочку «Allow customers to place orders without an account»
     (разрешить оформление без аккаунта).
   - Поставьте галочку на разрешение регистрации в личном кабинете.
   - **Важно:** снимите галочку «Generate password», если она включена —
     иначе WordPress будет присылать пароль на email вместо того, чтобы
     клиент придумывал его сам при регистрации (требует настроенной
     отправки почты, что не всегда работает из коробки на хостинге).

6. **Оплата.** `WooCommerce → Настройки → Платежи` → включите «Наличными
   при получении» (Cash on delivery). Переименуйте при желании в
   «Наличными/картой курьеру». Если позже понадобится приём онлайн-оплаты
   (например, ЮKassa) — это отдельный плагин, устанавливается независимо.

7. **Доставка/самовывоз.** Через SSH (если есть доступ к WP-CLI):
   ```
   wp eval-file scripts/setup-shipping.php
   ```
   Без SSH — вручную: `WooCommerce → Настройки → Доставка → Добавить зону
   доставки`, назовите «Москва» (или ваш город), добавьте два способа:
   «Фиксированная стоимость» (переименуйте в «Доставка») и «Самовывоз»
   (переименуйте в «Самовывоз»).

8. **Товары.** Через SSH/WP-CLI (рекомендуется — создаёт все 9 позиций
   сразу с фото и ценами, повторный запуск не создаёт дублей):
   ```
   wp eval-file scripts/import-products.php
   ```
   Без SSH — создайте товары вручную в `Товары → Добавить новый` по этой
   таблице (обычная цена — старая зачёркнутая, цена со скидкой — текущая):

   | Товар | Категория | Обычная цена | Цена со скидкой |
   |---|---|---|---|
   | Беляш | Выпечка | 120 | 90 |
   | Эчпочмак | Выпечка | 160 | 80 |
   | Баурсак | Выпечка | 200 | 150 |
   | Губадия | Выпечка | 200 | 120 |
   | Чак Чак | Выпечка | 120 | 70 |
   | Корт | Выпечка | 200 | 150 |
   | Азу | Горячее | 200 | 150 |
   | Токмач | Горячее | 200 | 150 |
   | Бешбармак | Горячее | 300 | 180 |

   Фото для каждого товара — в папке `assets/food/<название>.png`.

9. **Постоянные ссылки.** `Настройки → Постоянные ссылки` → просто нажмите
   «Сохранить изменения» (ничего не меняя). Это обязательный шаг — без
   него не будут работать страницы личного кабинета и оформления заказа.

10. **Проверка.** Оформите один тестовый заказ от начала до конца (как
    обычный клиент: зарегистрируйтесь, добавьте товар в корзину, выберите
    способ получения, оформите заказ) и убедитесь, что он появился в
    `WooCommerce → Заказы` — это и есть панель для обработки заказов.

## Что не входит в этот пакет

Плагин SQLite-интеграции и файлы `wp-config.php`/`router.php` использовались
только для локальной разработки без установки MySQL и в передаваемый пакет
не входят — на реальном хостинге обычно уже есть полноценный MySQL, который
WordPress использует по умолчанию.
