# Татарская кухня — сайт доставки

Одностраничный сайт-лендинг для доставки блюд татарской кухни, свёрстанный по готовому превью дизайна (без фреймворков — чистые HTML/CSS/JS).

## Что сделано

- Вёрстка всех блоков превью: шапка с навигацией и контактами, hero-баннер, секции «Выпечка» (6 позиций) и «Горячее» (3 позиции) с составом и ценами, блок «Акции» и футер «Контакты».
- Изображения блюд и промо-слайдов взяты из предоставленных архивов и расставлены по карточкам; из исходников слайдера вырезаны чистые фотографии без лишнего запечённого в PNG текста интерфейса.
- Слайдер акций с автопрокруткой, стрелками и точками-индикаторами (`script.js`).
- Адаптивная вёрстка для планшетов и телефонов, включая мобильное меню-бургер, которое выезжает справа поверх контента (оверлей + анимация), не сдвигая остальные элементы страницы.
- В футер добавлена встроенная карта (Яндекс.Карты, iframe) с меткой расположения.

## Технологии

Чистые HTML5, CSS3 (Flexbox/Grid, CSS-переменные, медиа-запросы) и vanilla JavaScript — без сборщиков и зависимостей.

## Структура

```
index.html        — разметка страницы
style.css         — стили
script.js         — слайдер, мобильное меню, интерактив карточек
assets/img/       — изображения блюд и промо-слайдов
```

## Запуск

Открыть `index.html` в браузере, либо поднять локальный статический сервер, например:

```
python -m http.server 8080
```

и перейти на `http://localhost:8080`.
